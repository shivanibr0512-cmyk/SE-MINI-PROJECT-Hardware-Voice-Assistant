# Hardware-Based Voice Assistant for Multimedia Controls

## Software Engineering Mini Project

**Team:** H6

## Project Description

The Hardware-Based Voice Assistant for Multimedia Controls is designed to let users control multimedia playback using predefined voice commands. The system captures voice input through a microphone, recognizes commands and maps them to the corresponding multimedia operations.

## Technologies

- Raspberry Pi / ESP
- Python
- MediaPipe
- Microphone
- Multimedia player

## Supported Commands

- Play
- Pause
- Resume
- Volume Up
- Volume Down
- Next
- Previous

## System Workflow

User → Microphone → Voice Recognition → Command Processing → Multimedia Control → Media Player
