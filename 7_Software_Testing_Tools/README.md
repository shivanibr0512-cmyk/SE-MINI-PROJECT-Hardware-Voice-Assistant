# Software Testing Tools

## Project
Hardware-Based Voice Assistant for Multimedia Controls

## Purpose
This folder documents software testing, bug fixing, patch implementation and retesting activities.

## Testing Activities
- Test voice command recognition.
- Test play, pause and resume functionality.
- Test volume up and volume down.
- Test next and previous media controls.
- Test invalid and unrecognized commands.
- Test error handling.

## Bug Fixing Process
1. Identify and document a software defect.
2. Reproduce the defect.
3. Use an AI tool or suitable development tool to help investigate and fix the bug.
4. Apply the patch.
5. Retest the affected functionality.
6. Record the actual result and supporting evidence.

## Evidence to Include
- Screenshots of the testing tool.
- Bug description and the fix applied.
- Relevant code changes or patch.
- Retest results showing whether the issue was resolved.

## Evidence Status
Actual testing results and screenshots will be added after testing the implementation.
